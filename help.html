Start, stop & update

  • Run Setup LiveDesk.cmd once after extracting the download.
  • Start LiveDesk.cmd starts the collector and dashboard, then opens your browser.
  • Stop LiveDesk.cmd stops both, including chat downloaders.
  • Update LiveDesk.cmd lets you select an official project release ZIP. It preserves your settings and history and creates a backup. If file installation or verification fails, it restores the previous application files and Python environment.
  • Closing the browser leaves collection running. Start-at-login is optional in Settings.

Common fixes

  • Setup fails: install Python 3.11 or newer from python.org, extract the ZIP into a writable folder, check your internet connection, and rerun Setup. Read setup.log for details.
  • No streamers: new installations start empty. Add handles in Settings.
  • No new messages: check that collection and Monitor are enabled and the desired recording types are checked. Check the stream is live.
  • Port 8765 is busy: another LiveDesk installation or application may be using it. Stop that copy before starting this one.
  • YouTube connection errors: check your internet connection. Public restricted chats may be unavailable. Temporary failures retry automatically.
  • After moving folders: disable and re-enable Start at login from the new location.
